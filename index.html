Paramètres

Aide

Notes Me permet de créer des notes synchronisées avec Google Drive, avec catégories, tags, favoris, corbeille et pièces jointes locales.

Recherche avancée

Exemples utilisables dans la barre de recherche :

  • #urgent pour filtrer par tag.
  • category:client pour filtrer par catégorie.
  • fav:true pour afficher les favoris.
  • has:file pour afficher les notes avec pièce jointe.
  • has:pdf pour afficher les notes avec PDF.
  • "facture impayée" pour rechercher une expression exacte.

Raccourcis

  • N : nouvelle note.
  • Ctrl + S : enregistrer depuis l’éditeur.
  • Échap : fermer la fenêtre active.
